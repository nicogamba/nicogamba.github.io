About me

I'm a Tech Lead Backend & Cloud Architect based in La Plata, Buenos Aires (Argentina, UTC-3, EU/US overlap). For the past 7+ years I've been designing, scaling and stabilizing production backend systems, with a strong focus on high-concurrency e-commerce, multi-tenant SaaS and cloud infrastructure on AWS.

Today I lead a cross-functional squad at easycommercetech. I also co-founded Orbix-IT, an independent SaaS venture where I architected an event-driven, multi-tenant B2B SaaS platform from scratch. I've refactored monolithic cores toward Domain-Driven Design, built multi-ERP integration layers and managed production Kubernetes/AWS infrastructure with Infrastructure as Code (Terraform, Helm). I care about clean architecture, measurable results and growing the teams I work with.

I also integrate production LLM pipelines and agentic workflows — DeepSeek, Claude and OpenCode — to automate spec generation, code review and quality gates, and I use Node.js, NestJS and TypeScript for proof-of-concepts and integrations.

Dockerized · Swagger · unit + e2e tests
