High-volume cart concurrency

A critical bottleneck at easycommerce®: carts with thousands of items, each evaluating taxes and promotions, severely degraded the API. I refactored unit-by-unit adjustment evaluation to async processing with Symfony Messenger and cronjobs.

~40% faster peak response times

Spec-first agentic pipeline

At Orbix-IT I designed a 3-stage pipeline: agents generate specs, a team of agents audits them, and a separate team implements the validated specs. DeepSeek/OpenCode workflows automate review and quality audits, with human review as the gate.

Specs validated before code is written

Multi-tenant cloud ownership

As sole infrastructure owner I ran the AWS stack (EKS, RDS, Redis, SQS, SNS, CloudFront, ELB) provisioned with Terraform, Helm and SOPS, running staging and production deploys while keeping full backend delivery.

~30% lower operational costs

  • NestJS

Event-driven e-commerce API (NestJS PoC)

A production-oriented PoC of an Order & Inventory API built with NestJS 11 and strict-mode TypeScript. Orders and inventory communicate only through domain events (order.created → inventory.reserved → inventory.reservation.failed), with transactional stock using pessimistic locks and price snapshotting — the same concurrency problems I solve daily in Symfony, applied in Nest.

Dockerized · Swagger · unit + e2e tests
